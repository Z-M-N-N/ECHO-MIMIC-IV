
## 一、项目概述

本项目基于 `/home/mzhao/ECHO-MIMIC-IV/data/regression.csv` 中定义的若干回归任务，使用 **Qwen2.5-VL-3B** 与 **VideoMAE** 两类视觉骨干网络进行视频/图像序列的回归预测。所有子项目代码分别置于 `/home/mzhao/ECHO-MIMIC-IV/model` 下的对应文件夹中，输出（特征、结果、图片）统一分类保存至 `/home/mzhao/ECHO-MIMIC-IV/out`。

## 二、数据说明

- **数据文件**：`/home/mzhao/ECHO-MIMIC-IV/data/regression.csv`
- **内容**：包含若干回归任务的标注数据（每个任务对应一个回归目标列），是本项目回归预测任务的唯一数据来源。
- **使用要求**：
  - 需先解析 CSV，明确各回归任务的目标列、样本 ID 及对应的视频/图像路径字段。

  - 各回归任务的标签需做标准化（z-score）或按需归一化，评估时反归一化回原尺度报告指标。

## 五、各子项目具体要求

### 通用要求
1. **输入处理**：视频帧采样策略（帧数、分辨率）需在 `config.yaml` 中可配置；图像任务同理。
2. **回归头（MLP）**：至少两层全连接 + 激活 + Dropout，输出维度等于回归任务数（多任务）或单任务。
3. **训练**：AdamW 优化器、MSE（或 Huber）损失、学习率与 batch size 可配置；支持早停。
4. **评估指标**：每个回归任务分别报告 MAE、RMSE、R²（训练/验证/测试）。
5. **可复现**：固定随机种子，记录配置文件到输出目录。
6. **特征保存**：冻结类项目必须将提取特征保存至 `out/features/<子项目>/`，便于复用与对比。

### 子项目 A：Qwen 冻结视觉塔 + MLP
- 仅加载 Qwen 视觉塔权重，输入视频/图像 → 输出视觉特征（pooled embedding）。
- 特征一次性提取并缓存，MLP 训练阶段直接读取缓存特征。
- 输出：特征文件、MLP 权重、各任务指标、训练曲线与预测散点图。

### 子项目 B：Qwen LoRA + MLP
- 视觉塔注入 LoRA（指定 target modules 与 rank），其余参数冻结。
- LoRA 与 MLP 联合训练，端到端前向（不缓存特征）。
- 保存 LoRA adapter 权重 + MLP 权重；输出同 A。

### 子项目 C：VideoMAE 冻结 + MLP
- 加载 `pytorch_model.bin`，冻结 backbone，提取视频特征并缓存。
- 训练 MLP 回归头；输出同 A。

## 六、输出规范

所有产出统一放在 `/home/mzhao/ECHO-MIMIC-IV/out`，按 `features / results / figures` 三大类，再按子项目名分子目录：

- `out/features/<子项目>/`：`*.npy` 或 `*.pt` 特征文件（含样本 ID 映射）。
- `out/results/<子项目>/`：`metrics.json`（各任务 MAE/RMSE/R²）、`predictions.csv`、`config.yaml` 副本。
- `out/figures/<子项目>/`：`loss_curve.png`、`pred_vs_true_<task>.png` 等。

## 七、验收标准

1. 三个子项目均可独立运行（`python train.py --config config.yaml`）。
2. 每个回归任务均输出 MAE / RMSE / R² 三项指标。
3. 冻结类项目特征文件成功保存，且 MLP 训练可复用缓存特征。
4. LoRA 项目成功保存 adapter 与 MLP 权重。
5. 输出目录结构符合第六节规范。
