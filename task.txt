## 一、项目概述

本项目基于 `/home/mzhao/ECHO-MIMIC-IV/data` 中的分类标注数据，使用 **Qwen2.5-VL-3B 端到端多模态前向**：将超声心动图视频（或采样帧）与**任务提示词（prompt）**一同输入模型，取模型**隐空间表征**（LLM 主干在指定 token 位置的 hidden state）作为样本特征，接入 MLP 分类头；训练阶段通过 **LoRA 微调 LLM 主干**（视觉塔是否参与微调由配置决定），MLP 分类头全参数训练。

当前阶段聚焦于**单一分类任务的原型验证**：比较**单视角输入**与**双视角输入（A4C、A2C）**在端到端 LoRA 微调下的分类性能差异（以 A4C、A2C 单视角为基线，对比 A4C+A2C 融合/联合输入的效果）。

所有代码置于 `/home/mzhao/ECHO-MIMIC-IV/model/qwen/`（建议新建独立子目录如 `qwen/e2e_lora/`），输出（结果、图片、LoRA 权重、日志）统一保存至 `/home/mzhao/ECHO-MIMIC-IV/out`。

> 说明：本阶段**不再**采用"视觉塔冻结 + 特征一次性缓存"的方案；端到端前向是训练循环的一部分。若为加速仍希望缓存视觉侧 embedding，需在文档中明确其与端到端训练的差异及对结论的影响（默认不缓存，保证端到端一致性）。

## 三、模型与训练策略

### Qwen2.5-VL-3B（端到端前向 + LoRA 微调 + MLP 分类头）

- **模型路径**：`/mnt/disk5/mzhao/公共大模型/Qwen2.5-VL-3B`
- **端到端前向**：
  - 输入 = 任务提示词（文本）+ 视频/采样帧（视觉）+ 视角标识（A4C / A2C / 双视角）。
  - 提示词需在 `config.yaml` 中可配置模板，明确任务语义（如"这是一段超声心动图 A4C 视角视频，请判断其 <任务名> 类别"），并在末尾放置**表征提取锚点**（如最后一个 token 或专用占位 token），统一从该位置取 hidden state。
- **隐空间表征提取**：
  - 取 LLM 主干**最后一层**（或配置指定层）在锚点位置的 hidden state 作为样本表征向量，维度 = LLM hidden size。
  - 提取层号、锚点位置策略、是否做 mean-pooling 均在 `config.yaml` 中可配置并记录。
- **LoRA 微调**：
  - 在 LLM 主干的注意力/FFN 线性层注入 LoRA（rank、alpha、dropout、target_modules 可配置）；**视觉塔默认冻结**（若配置允许解冻，需记录并说明显存与稳定性影响）。
  - 仅 LoRA 参数 + MLP 分类头可训练；其余参数冻结。
  - 需记录可训练参数量与总参数量占比。
- **MLP 分类头**：至少两层全连接 + 激活 + Dropout，输入维度 = LLM hidden size（双视角为融合后维度），输出维度 = 该任务类别数。
- **双视角处理**（端到端方案下的两种可选实现，配置中指定）：
  1. **联合输入（joint）**：将 A4C 与 A2C 帧按视角标记组织进同一次前向（如两段视觉输入 + 视角分隔提示），从锚点取一次表征；
  2. **表征级融合（late fusion）**：两视角分别前向取表征，再在表征层做 `concat` / `mean` / `attention` 融合后送入 MLP。
  - 单视角实验即为该视角单独前向取表征送入 MLP。
  - 需在文档中记录所选方案与输入组织方式。

## 六、具体要求

### 通用要求
1. **输入处理**：视频帧采样策略（帧数、分辨率）在 `config.yaml` 中可配置；**任务提示词模板**、**视角组合方式**（单视角 / 双视角及联合或晚期融合）也可配置。
2. **表征提取**：明确并实现从 LLM 隐空间取表征的逻辑（层号、锚点 token 位置、pooling 方式），在配置中可调，并在结果中记录。
3. **LoRA 配置**：rank、alpha、dropout、target_modules、是否解冻视觉塔均需可配置；训练开始时打印/记录可训练参数量及占比。
4. **MLP 分类头**：至少两层全连接 + 激活 + Dropout，输出维度等于该任务类别数。
5. **双视角融合**：实现并在配置中可选 `joint`（联合输入）与 `concat` / `mean` / `attention`（表征级融合）；记录所选策略与输入维度。
6. **训练**：AdamW 优化器（可为 LoRA 与 MLP 设不同学习率）、交叉熵损失（支持 class weight / focal loss）、学习率与 batch size 可配置；支持早停（基于验证集 macro-F1 或 accuracy）；支持梯度累积/混合精度以适配显存。
7. **评估指标**：报告 Accuracy、macro-F1、macro-AUC（二分类另报 Precision/Recall/Sensitivity/Specificity），并输出混淆矩阵。
8. **可复现**：固定随机种子，将配置文件副本写入对应结果目录；记录环境与关键超参。
9. **对照实验**：在同一任务、同一数据划分、同一 prompt 模板与 LoRA 配置下，分别运行：
   - 基线 1：单视角 A4C 输入
   - 基线 2：单视角 A2C 输入
   - 实验组：A4C + A2C（联合输入或表征级融合，至少一种，建议以联合输入为主、表征级融合作补充）
   并汇总对比表（各指标 + 提升幅度）。
10. **效率与显存**：说明端到端训练的相对开销（相比冻结特征方案），记录单卡显存占用与单 epoch 耗时；若采用梯度累积/混合精度/冻结视觉塔等手段，需在文档中说明。

## 八、验收标准

1. 子项目可独立运行：`python train.py --config config.yaml` 即完成端到端 LoRA 微调 + MLP 训练（可选 `evaluate.py` 单独复评）。
2. 端到端前向链路正确：视频/帧 + prompt 输入 Qwen2.5-VL，从指定锚点取出隐空间表征并送入 MLP；LoRA 仅注入指定模块，视觉塔默认冻结，可训练参数量有记录。
3. 选定任务上，完成 A4C 单视角、A2C 单视角、A4C+A2C 三组实验，均输出 Accuracy、macro-F1、macro-AUC 及混淆矩阵。
4. 生成单视角 vs 双视角的对比汇总，明确给出双视角相对单视角的提升（或未提升）结论。
5. 三组实验使用相同数据划分、随机种子、prompt 模板与 LoRA 配置，结果可复现；best LoRA + MLP 权重已保存。
6. 输出目录结构符合第七节规范。
7. 项目目录已清理：无冗余/无关代码与产出，清理记录见 `CLEANUP.md`，本任务链路可独立跑通。
